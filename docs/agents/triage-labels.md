# Labels de triage

Les skills parlent de cinq rôles de triage canoniques. Ce fichier fait correspondre chaque rôle au label utilisé dans Linear (équipe Maxime). Les labels absents de Linear sont créés au premier besoin avec `create_issue_label`.

| Rôle dans mattpocock/skills | Label dans Linear | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | À évaluer |
| `needs-info` | `needs-info` | En attente d'informations du demandeur |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifié, prêt pour un agent autonome |
| `ready-for-human` | `ready-for-human` | À implémenter par un humain |
| `wontfix` | `wontfix` | Ne sera pas traité |

Quand une skill mentionne un rôle (ex. « appliquer le label prêt pour un agent »), utiliser le label correspondant de ce tableau.
